# Neuralab — мини-Трелло для команды

Простое приложение для управления задачами подчинённых. Работает в локальной сети офиса без интернета.

## Что умеет (MVP)

- Доска с колонками: «К выполнению», «В работе», «Готово»
- Карточки задач с названием, описанием, исполнителем и дедлайном
- Перетаскивание карточек между колонками (drag-and-drop)
- Авторизация (роли: руководитель / сотрудник)
- Отчёты: задачи по сотрудникам за период, просроченные, среднее время выполнения
- Управление сотрудниками (только руководитель)

## Архитектура

Одно приложение работает в двух режимах:
- **Сервер** — на одном компьютере в офисе (запускается автоматически)
- **Клиент** — на компьютерах сотрудников, подключаются по локальной сети

База данных — SQLite, один файл, хранится на компьютере-сервере.

## Установка для разработки

```bash
npm install
npm start
```

При первом запуске откроется окно с выбором: «Запустить как сервер» или «Подключиться».

### Логин по умолчанию

- Логин: `admin`
- Пароль: `admin`

**Обязательно создайте новых пользователей и поменяйте пароль администратора после первого входа.**

## Сборка установщика

```bash
# Для Windows (.exe)
npm run build:win

# Для macOS (.dmg)
npm run build:mac
```

Установщик появится в папке `dist/`.

## Как использовать в офисе

1. На одном компьютере (который будет всегда включён) установить приложение и выбрать **«Запустить как сервер»**. Записать показанный адрес вида `http://192.168.1.10:4317`.
2. На остальных компьютерах установить то же приложение, выбрать **«Подключиться»** и ввести этот адрес.
3. Войти под `admin` / `admin`, создать сотрудников через раздел «Сотрудники», раздать им логины/пароли.

## Бэкап

Файл базы данных находится в папке `userData` Electron:
- Windows: `%APPDATA%/Neuralab/neuralab.db`
- macOS: `~/Library/Application Support/Neuralab/neuralab.db`

Рекомендуется копировать его в облако или на внешний диск раз в день.
